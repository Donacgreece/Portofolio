01 / FLAGSHIP PRODUCTPrivate hospitality platform

TableMaster

Hospitality ordering and table operations

A full-stack Flask application built to manage restaurant tables, reservations, users, orders, products, VAT, reporting and network printing from one operational interface.

  • Implements PIN-based users and roles, configurable sessions, table status, reservations, product management, order history, payments and audit logging.
  • Routes order items to the correct ESC/POS network printer by category, checks printer availability and stores failed jobs in persistent retry queues.
  • Uses SQLite for operational and audit data, Excel imports for catalogue maintenance, scheduled background jobs, backups, restore safeguards and PWA support.
  • Includes MAC-bound encrypted licensing built with Fernet for controlled application deployment.
